Commands

Asking

/snack add an Amazon link, or a catalog keyword

/snack list the week so far, with the budget line

Right-click a message → Add as snack

Deciding

/snack digest run the weekly cut now

/snack budget show or change the cap

/snack flag an allergen warning

Buying

Mark as ordered on the digest

/snack unavailable couldn’t buy it

/snack substitute bought something else

Afterwards

/snack rate was it worth it — private

/snack repeat clone last week’s order

/snack help all of the above, in Discord

Non-food items are refused on Amazon’s own department; the Official Snack Buyer can override deliberately. Anything touching a company card should go past InfoSec first.
